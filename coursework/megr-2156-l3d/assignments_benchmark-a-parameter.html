Benchmark a Parameter

Design

Sometime in the future, during this class I'm sure I will print out something that requires a horizontal beam/bridge to go across connecting to something else. I also will eventually have to check and see the limitations set for an overhang. The parameters I decided to test was to see the affects of a bridge and an overhang had on a design/3D print specifically without any supports. I decided to push the limits of the parameters of my design in hopes that I will be able to see how and where failure occurs to prevent any future failures when replicating prints that may have the same or some of the same elements. I opened SolidWorks and got my design started. Once in SolidWorks I was sure to change the units to IPS.

 

Right off the bat I knew I wanted to have a main tower and build off from there. When I was originally planning the design I wanted to create a sort of leaf/flower design where there are "petals" on either side of the main tower, to test the overhang. I decided to go with the base to be set at 1.5 inches and the height set at 6 inches. I did this using the smart dimension tool. 

Using the 3 point arc tool in SolidWorks I was able to create the following design. 

Then I made one almost identical to it, to create the "leaf petal" look.

I then connected them using the line tool. This created the design to become a single member. 

Then using the trim tool to officially make it a single part. 

I didn't like the way that it looked, so for aesthetic reasons I decided to fillet the edges of the petal. Using the sketch fillet tool.

It looked even worse when I filleted the big edge, so I decided to leave that one as it was and only fillet the small edge. 

I wanted to give it a sort of "sprouted" look, and I did this by using the Mirror tool. Setting a centerline first, then selecting the entities to mirror, and lastly using the centerline to mirror it about. 

After executing that, this is how it looked. 

Again I thought it could be more aesthetically pleasing so I also filleted the top corners of the main tower.

After that was complete I moved on to Boss Extruding it. I made the dimension for this to be 1.5 inches. 

What it looked like after that was complete. 

Next it was time to move on to the bridge section of the design. I wanted to test the overhang as well as the bride in the same print so I could gain more knowledge about the 3D printing process as a whole. I started a new sketch. Clicked on the surface that I wanted to sketch on, and then made a rectangle using the rectangle tool, leaving the dimensions the same size as the overhangs. 

Once complete I executed a Boss Extrude for the design. In doing this I made the dimension sick out 3.5  inches, and changed directions making the next side also 3.5 inches sticking out, but I had to account for the width of the previous Boss Extrude making the overall length 5 inches.

After the feature was executed this is how it looked. 

I now moved on to making two separate (thinner) towers to form the bridge for this design. I did this by creating two identical rectangle shapes on either side. I kept this thinner also just so that the print time didn't take as long. I made the length the same as the previous Boss Extrude, and the width 0.15 inches. 

I then Boss Extruded the bridge towers to match the same height as the main tower. 

This was my final product after I sketched everything. 

After seeing the final product I wasn't quite satisfied with my design. I felt like it looked a little too chaotic and sloppy (in a sense). After considering how the parameters and geometry of the design looked I knew I wanted to switch it up. I realized that I didn't need two bridges or two of the same types of overhangs for this assignment. It was a little overkill, and I wanted to change it. I then also realized that the overhangs I had on my design would eventually just start printing in mid air if I didn't add any supports, since the 3D printer starts from the bottom and works its way up. I decided to have only one overhang and one bridge in my design (instead of two of the same ones). I went back through my sketches and trimmed away all but one overhang and one bridge. However before that I thought of making two different sized bridges and two different sized overhangs, but after thinking about it over again I realized this whole time I wasn't really accounting for the print time for my sketch. Here is the process of my thoughts before deciding to go with one bridge and one overhang. 

Once I got to the previous part above, that was when I decided to go back and delete the bridges but left the tallest overhang. I wanted to change the location of the bridge and have it come across the top of the main tower to the top of the thin tower. I changed up the look of the bridge to match the top of the main tower. I added a rectangle that was the same size as the fillet.

I then used the spline tool to make an identical match with the fillet of the main tower. 

Next I trimmed away the edges so that everything matched up perfectly. 

It was now time to make the length of the bridge. Since I chose to do only one bridge this go around, I wanted to make it longer. So I Boss Extruded it to be 5 inches. 

How the design looked after that feature was applied. 

Next it was time to add the new thin tower (since the other bridges were deleted). I opened the sketch tool and made a rectangle.

I clicked the smart dimensions tool and set it to be 0.15 inches wide, keeping the length the same as the bridges width. 

It was now time to Boss Extrude. I also made it 6 inches so that the two towers would be level with one another. 

After executing the feature this is how it looked. 

It was now time to save my design and upload it to the PrusaSlicer. First I had to save my design as a .step file. 

Once saved it is time to open the PrusaSlicer software. 

Then upload your .step file. Wow let me tell you I didn't realize the sizing of my design. I was getting all sorts of warnings on the PrusaSlicer software warning me of how the design too big. 

I thought maybe it would fit properly if I changed it orientation but it still was overall too tall for the 3D printer. This was definitely a mistake not taking the 3D printers printing capability of its height and width into consideration. 

Thankfully I knew how to scale my print down without it actually changing the deign itself.

I then wanted the print to be 5 inches tall, however even with that the print time was a little too long in my opinion, and I didn't want to take over a 3D printer too long in case someone else wanted to use it. So I was trying to keep the print time at an hour or less.

The print time for the 5 inch scale.

I played around with the settings some. I also wanted to make sure that automatic supports were not added to the design when it came time to print. I made sure to check off the "Auto generate supports" box in the settings. 

I then wanted to change the Fill density to 15% and the Fill pattern to Cubic instead of Grid. 

I also played around with the vertical and horizontal perimeters in the print settings. I did this to see how this affected the overall structure of my design.

Once this was all complete it was time to do an overview of my print before uploading it to the printer. After I clicked slice I took a look at the internals like the infill and the perimeters.

I even noticed that the infill was also able to be printed into my bridge. I was curious how this would turn out after the first layer of the bridge printed.

Finally I did one last overview before uploading it to the flash drive. I used printer #1 for my assignment. This is the prompt screen when plugging in the flash drive after upload. Confirm the print is yours and press the print button. 

Once print is initiated this screen will prompt the print is in session. 

The red light will also come on before calibrating the machine. You can see below my print time was estimated at 46 minutes. 

Once print is first starting the percent will change.
