# Portfolio Content Roadmap

## Highest-priority additions
1. Mechatronics II vibrating-beam project: final setup photos, circuit diagram, LabVIEW screenshots, calibration chart, response plot, final memo.
2. Freshman Design project: objective, constraints, role, sketches, final CAD, prototype/testing, result.
3. Additive Manufacturing project: part objective, print method/material, design-for-additive decisions, slicer settings, print outcome, defects, revisions.
4. Team Design Project: clearly separate individual contributions from team outcomes.

## Standard project case-study structure
- One-sentence project summary
- Course and date
- Individual role
- Problem / user need
- Requirements and constraints
- Tools and methods
- 3–6 process images
- Engineering calculations or data
- Final result
- Validation / testing
- What failed or changed
- Downloads appropriate for public release

## Image preparation
- Prefer 1600 px maximum width for large images.
- Use WebP or compressed JPEG.
- Crop out unrelated desktop areas and personal information.
- Give each image a descriptive filename and alt text.
- Use final renders and test results before click-by-click software screenshots.
